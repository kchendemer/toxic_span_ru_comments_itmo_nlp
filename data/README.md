# Разбиение русскоязычных комментариев для разметки

Датасет проекта Toxic Span RU: 14 412 комментариев с исходной бинарной меткой
токсичности. Train и validation распределены между четырьмя участниками;
test хранится отдельным общим файлом.

Исходный датасет из авторского ноутбука: `blackmoon/russian-language-toxic-comments`
на Kaggle. Здесь используется уже сохранённый `labeled.csv`; повторное скачивание
для работы с разбиением не требуется.

## Файлы

```text
requirements.txt
data/
├── README.md
└── raw/
    ├── labeled.csv                  # исходные комментарии и метки
    ├── data.ipynb                   # весь код разбиения и проверок
    └── raw_data_splits/
        ├── train_part_1.csv … train_part_4.csv
        ├── validation_part_1.csv … validation_part_4.csv
        └── test.csv

```

## Распределение между участниками

Участник с номером N получает `train_part_N.csv` и `validation_part_N.csv`.
Номера обозначают части, имена участников в данных не зафиксированы.

| Часть | Train | Validation | Всего для участника |
| --- | ---: | ---: | ---: |
| 1 | 2 883 | 361 | 3 244 |
| 2 | 2 882 | 360 | 3 242 |
| 3 | 2 882 | 360 | 3 242 |
| 4 | 2 882 | 360 | 3 242 |
| Всего | 11 529 | 1 441 | 12 970 |

Отдельный test содержит 1 442 строки. Разбиение приблизительно соответствует
80% / 10% / 10%; различие на одну строку связано с округлением размеров выборок.

В исходном файле две колонки: `comment` и `toxic`. В частях добавлена
`comment_id` — уникальный пятизначный идентификатор, а не номер исходной строки.
`toxic` содержит исходную метку: `0.0` — нетоксичный, `1.0` — токсичный комментарий.
CSV частей используют UTF-8 с BOM (`utf-8-sig`).

## Запуск ноутбука

Нужны Python 3.10+ и зависимости из корня репозитория:

```bash
python3 -m pip install -r requirements.txt
python3 -m jupyterlab
```

Откройте `data/raw/data.ipynb` и выполните все ячейки сверху вниз.

Весь код находится в одном ноутбуке: загрузка исходных данных, назначение ID,
разбиение, проверки и итоговая таблица. Обычный запуск не записывает файлы.

## Алгоритм разбиения

1. `numpy.random.default_rng(42)` назначает ID без повторов из диапазона
   `[10000, 100000)` в исходном порядке строк.
2. `train_test_split` с `test_size=0.20`, `random_state=42`, `shuffle=True`
   отделяет временную выборку от train.
3. Второй `train_test_split` с `test_size=0.50` и теми же параметрами делит
   временную выборку на validation и test.
4. `numpy.array_split` делит train и validation на четыре последовательные части.

Стратификация в исходном алгоритме не использовалась. Тексты не очищаются:
пробелы, пунктуация и переводы строк сохраняются. Версии библиотек зафиксированы
в `requirements.txt`. 

## Работа с разметкой

Сохраняйте результаты разметки сохраняются отдельно в `data/annotated/`.
Используйте `comment_id` для сопоставления с исходным комментарием.
Не меняйте `comment` и `comment_id`: изменение текста сдвинет позиции
размеченных фрагментов, а изменение ID нарушит сопоставление результатов.
Файлы `data/raw/` остаются эталоном для проверки.
